# Responsive IT Portfolio Website

A clean, responsive personal portfolio website designed from scratch using clean semantic HTML5 structures and vanilla CSS3 layouts. Specially optimized for Information Technology students.

## Description
This website serves as a digital professional business card to showcase a detailed profile, core IT competencies, recent structured projects, education pathways, and an accessible interface to reach out directly via contact links.

## Technologies Used
* **HTML5** - Layout building blocks.
* **CSS3** - Custom properties, Flexbox alignment, and responsive Grid components.
* **FontAwesome Icons** - Standard visual indicator icons.
